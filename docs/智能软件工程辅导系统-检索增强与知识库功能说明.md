# 智能软件工程辅导教学助手 - 检索增强与知识库功能说明

## 功能概述

智能软件工程辅导教学助手已实现检索增强(RAG)和知识库构建功能，主要包括以下几个方面：

1. **检索增强生成(RAG)**：通过混合检索技术提高大模型回答的准确性和相关性
2. **多源知识库构建**：整合结构化与非结构化数据，建立完整的软件工程知识体系
3. **知识图谱**：构建概念关系网络，支持语义理解和知识推理

## 功能详细说明

### 1. 检索增强生成(RAG)

系统采用检索增强生成(Retrieval-Augmented Generation)技术，显著提升大模型回答的准确性和专业性。

#### 架构设计
整体流程如下：
1. 用户提问 → 
2. 检索模块处理 → 
3. Elasticsearch检索相关内容 → 
4. 获取相关代码片段和知识点 → 
5. 大模型结合检索结果生成回答 → 
6. 返回最终答案

#### 实现技术
- **向量化技术**：使用Sentence-BERT将课程资料向量化存储，支持语义检索
- **混合检索策略**：结合BM25算法和语义向量检索，提升召回率
- **上下文增强**：将检索到的相关内容作为上下文提供给大模型，提高回答准确性
- **相关性排序**：对检索结果按相关性进行排序，确保最相关内容优先被使用

#### 性能指标
- 通过BM25+语义混合检索提升召回率，对比实验证明准确率提升≥30%
- 平均响应时间控制在2秒以内
- 支持复杂多轮对话中的上下文相关检索

### 2. 多源知识库构建

系统整合多种数据源，构建全面的软件工程知识库，为检索和问答提供基础。

#### 数据源类型

1. **结构化数据**
   - 课程大纲（XML/JSON格式）
   - 习题库（包含题目、答案、难度分级）
   - UML案例库（各类图表及其说明）
   - 设计模式示例集（代码实现与应用场景）

2. **非结构化数据**
   - 教材PDF解析（使用PyMuPDF提取文本和图像）
   - MOOC视频字幕（使用Whisper ASR技术提取）
   - 学术论文（提取关键概念和方法）
   - 代码示例（带注释的软件工程实践代码）

#### 处理流程
1. 数据采集：从多种来源获取原始数据
2. 数据清洗：去除噪声、标准化格式
3. 内容提取：分离文本、代码、图表等元素
4. 知识组织：按主题、概念进行分类
5. 索引建立：创建全文检索和向量索引

### 3. 知识图谱

系统构建了软件工程领域的知识图谱，实现概念间的关联和推理。

#### 实现技术
- **图数据库**：使用Neo4j存储概念实体和关系
- **推理引擎**：通过Apache Jena实现基于规则的推理
- **实体关系提取**：使用NLP技术从文本中提取实体和关系

#### 知识图谱结构
- **节点类型**：概念、设计模式、原则、技术、应用场景等
- **关系类型**：包含、应用、继承、实现、对比等
- **属性信息**：定义、示例、难度级别、应用频率等

#### 应用场景
- 构建概念关系网（如"继承→设计模式→工厂模式"链路）
- 实现推理规则（如"设计原则→开闭原则→应用场景"）
- 支持知识探索和可视化

## 使用技术栈

### 1. 检索增强(RAG)技术栈

- **向量数据库**：Elasticsearch (用于全文检索和向量存储)
- **向量化模型**：Sentence-BERT (用于语义向量化)
- **检索算法**：BM25 + 语义向量混合检索
- **大语言模型集成**：LangChain4j框架

### 2. 知识库构建技术栈

- **数据处理**：
  - PyMuPDF (PDF文档解析)
  - Whisper ASR (音频转文字)
  - Beautiful Soup (网页内容提取)
  
- **数据存储**：
  - MySQL (结构化数据)
  - Elasticsearch (全文检索)
  - Milvus/内存向量存储 (向量数据)

- **知识图谱**：
  - Neo4j (图数据库)
  - Apache Jena (推理引擎)
  - D3.js (前端可视化)

## 使用指南

### 1. 检索增强问答

1. 进入系统聊天界面
2. 输入专业问题，如"请解释单例模式的线程安全问题"
3. 系统会自动检索相关知识，并结合大模型生成专业回答
4. 回答中会包含引用来源，可点击查看原始内容

### 2. 知识库浏览

1. 访问系统的知识库页面
2. 可按主题、概念或关键词浏览知识内容
3. 点击概念查看详细解释和相关内容
4. 使用筛选功能定位特定类型的知识

### 3. 知识图谱探索

1. 访问知识图谱可视化界面
2. 输入起始概念，如"设计模式"
3. 系统展示该概念的关联网络
4. 可交互式探索，点击节点展开更多关联
5. 使用推理功能发现隐含关系

## 注意事项

1. RAG检索需要预先构建知识库索引，首次使用前请确保索引已建立
2. 知识图谱推理在复杂查询时可能需要较长处理时间
3. 系统回答依赖于知识库质量，对于知识库未覆盖的领域，准确性可能有限
4. 大型PDF文件处理可能需要较长时间，请耐心等待
